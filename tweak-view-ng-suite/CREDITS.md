# Credits

Tweak View NG is an independent, ground-up reimplementation for the Jayofelony
Pwnagotchi fork. It would not exist without the plugins that pioneered live,
on-device UI editing for Pwnagotchi. Credit where it's due:

## Original *Tweak View*

**NurseJackass & Sniffleupagus** — the original "edit the UI on the fly" plugin
that started it all. Famously direct ("a terrible user interface — you can break
things"), it proved the idea that you should be able to move and restyle your
Pwnagotchi's screen elements live, from a browser.

## *Tweak View 2* (v2.0.0)

**Sniffleupagus & BraedenP232** — a rewrite with a nicer interface and the first
steps toward guardrails. From its source: *"Respects to NurseJackass/Sniffleupagus
for the original tweak_view plugin as we all know and love, which inspired this
rewrite with a less 'ugly interface' and maybe some guardrails."*

Maintained in Sniffleupagus's plugin collection:
<https://github.com/Sniffleupagus/pwnagotchi_plugins>

An `itsdarklikehell` fork of the original was also referenced during this
project's plugin audit.

## Tweak View NG

**patrickato** — the NG rebuild: a safe, resolution-independent, hardened editor
(drag/nudge/align/match/stack, named profiles, undo/redo, a recovery editor,
atomic saves, and a safe-property model) targeting Jayofelony 2.9.5.8 / 2.9.5.9.

NG carries those authors' ideas forward rather than their code — including an
automatic importer for existing Tweak View / Tweak View 2 layouts, so no one has
to start over.
